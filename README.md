# AI Week 3 – Machine Learning

This project is part of my **AI Internship Program at DevSphere**.

## 📌 Task Overview

In Week 3, I explored the fundamentals of **Machine Learning** by building a classification model using the **Iris dataset**.

The task focused on preparing the dataset, splitting it into training and testing sets, training a **Decision Tree Classifier**, and evaluating the model's performance.

## 🛠️ Technologies Used

* Python
* Pandas
* Scikit-learn
* Decision Tree Classifier
* Iris Dataset

## 🔍 What I Learned

* Basic Machine Learning workflow
* Loading and preparing datasets
* Training and testing data splitting
* Classification using Decision Trees
* Model evaluation
* Accuracy, confusion matrix, and classification report
* Understanding feature importance

## 📊 Result

The trained Decision Tree model achieved **96.7% accuracy** on the test dataset.

The model also showed that **petal measurements were highly important for distinguishing between Iris flower species**.
